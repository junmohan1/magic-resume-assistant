神奇网申助手 (ResumeFlow Mod)

> 一款纯本地运行、隐私绝对安全的 Chrome / Edge 浏览器扩展，专为秋招/春招海投简历设计。支持复杂网申系统表单的智能识别、多段经历自动扩充与精准填充。

在秋招和春招中，企业官网的网申系统往往需要填写大量重复且格式不一的信息。本项目通过强大的语义匹配算法与上下文纠偏逻辑，致力于将体力活自动化，让你把精力集中在笔试与面试上。

---

✨ 核心功能特性

 1. 🧠 智能语义与上下文匹配引擎
- 强大的同义词词库：内置数百个中英文字段别名规则，无论是“姓名”、“Name”、“申请人”，还是“工作职责”、“岗位描述”、“主要工作内容”，都能精准识别。
- 冲突保护与智能纠偏：内置“区域隔离”逻辑。例如，在“个人信息”中遇到“最近公司”时，只提取第一段公司经历但不占用后续队列名额，防止后续“工作经历”模块数据错位；能识别上下文，防止把“项目名称”错填为“姓名”。
- 下拉框智能检索：针对各类前端框架（如 Element UI、Ant Design 以及企业自研框架）伪装的下拉框，插件会自动触发点击、展开面板，并根据词库算法寻找最佳匹配选项并选中。

 2. 📑 多段经历自动化处理
- 自动点击“添加”：智能识别页面上的“+ 添加”、“新增经历”等按钮，根据简历中的段数，自动为你扩充表单坑位。
- 经历精准映射：支持多段教育经历、工作/实习经历、项目经历、校园/社团经历的顺序匹配。
- 校园与项目合并兼容：若网申系统仅有“项目经历”而无“在校经历”，插件会自动将你的在校经历数据合并至项目经历中填充（反之亦然）。

 3. 📅 极其复杂的日期组件适配
- 支持原生 `type="date"` 和 `type="month"` 控件。
- 支持现代框架的日历弹窗选择器（模拟点击年份、月份节点）。
- 分离式年月专杀：针对 Moka 等系统特有的“年-月 - 年-月”四个独立下拉框组合，能按顺序精准拆解填入，绝不串位。

 4. 🛡️ 隐私与文件防误传
- 纯本地解析：简历附件（PDF/DOCX）在浏览器本地完成解析，绝不发送到任何第三方服务器。
- 极致防误传白名单：内置严格的文件上传拦截机制。在识别到“外语资格证书”、“获奖附件”等模块时，绝不会自作主张上传你的头像或登记照。

🛠️ 安装与使用

1. 克隆或下载本项目源码并解压。
2. 打开 Chrome 或 Edge 浏览器，在地址栏输入 `chrome://extensions` (Chrome) 或 `edge://extensions` (Edge)。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”，选择本项目根目录。
5. 将“神奇网申助手”固定到浏览器工具栏。
6. 点击插件图标 -> 点击“编辑”进入设置页 -> 上传你的 PDF/DOCX 简历进行本地预解析，或手动完善多段经历。
7. 打开目标网申页面，展开表单区域，点击插件“开始检测并填写”。

⚠️ 兼容性与使用限制声明（必读）

虽然本插件经过了大量真实场景的测试与迭代，但国内招聘网站的前端技术栈极其繁杂。本插件基于标准 DOM API 与常规的前端事件流进行开发，因此可能对部分新兴互联网大厂（或使用了极其激进的前端架构的招聘系统）存在不适配现象。

 为什么会出现不适配？
1. 框架层级的双向绑定劫持（Proxy / DefineProperty）：现代前端框架（React/Vue）对输入框的状态有严格的管控。部分大厂系统为了安全，重写了底层事件，导致插件虽然将文本写入了输入框，但页面状态并未更新，提交时会变空。
2. 非标准组件与深度封装：有些系统弃用了原生 `<input>`，采用了富文本编辑器（如 Draft.js、Slate.js）或基于 Canvas 绘制的输入框。这类组件依赖极度复杂的键盘事件（Keydown / Keypress）模拟，直接赋值完全无效。
3. 虚拟列表与动态渲染：部分超长表单使用了虚拟滚动（Virtual Scroll），未滑动到的区域根本不渲染 DOM 节点，导致插件在初始扫描时无法发现隐藏的输入框。
4. 严格的 CSP（内容安全策略）与沙箱机制：出于防爬虫或安全考量，部分大厂系统会严格限制外部 Content Script 的执行，甚至将表单嵌套在封闭的 iframe 中，导致插件无法跨域注入逻辑。

如果你在投递某家公司时发现识别率极低，通常不是插件“坏了”，而是对方的前端架构过于封闭。请你遇到此类系统时采用手动填写😭。

🧪 开发与本地测试

本项目采用 Vanilla JS 开发，无第三方构建依赖。核心逻辑包含基础测试用例：

```bash
 核心字段匹配与选项打分测试
node core.test.js

 简历文本解析逻辑测试
node resume-parser.test.js

core.js：核心词库、打分算法与数据模型。

content.js：DOM 深度遍历、上下文提取、事件模拟与自动填充逻辑。

resume-parser.js：本地 PDF / DOCX 文本提取解析引擎。

🛡️ 隐私声明
本插件没有任何后端服务器。所有用户填写的个人资料、附件数据均通过 chrome.storage.local 存储在当前浏览器中。代码不会发起任何网络请求，请放心使用。
